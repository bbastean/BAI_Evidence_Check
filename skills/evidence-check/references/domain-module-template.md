# Domain Module Template

Copy this file, rename it for your field (for example `employment-law-module.md` or `clinical-evidence-module.md`), and fill in each section. Delete any section that doesn't apply. A module adds rules for one field on top of the core Evidence Check framework. It can tighten the core protocols but must never loosen them.

Keep a module short and concrete. Name real sources, real document types and real failure modes in your field. Generic advice already lives in the core skill.
